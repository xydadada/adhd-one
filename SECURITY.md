# Security policy

Please report vulnerabilities privately through GitHub's security advisory form for this repository. Do not include API keys, provider credentials, private prompts, or sensitive workspace data in an issue.

This project is an Electron shell around the official DeepSeek Harness runtime. If a report reproduces in the upstream CLI without this desktop shell, also follow the reporting instructions in the [official DeepSeek Harness repository](https://github.com/deepseek-ai/deepseek-harness).
