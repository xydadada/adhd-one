# Support

ADHD One is a volunteer, unofficial community project. It is not maintained or endorsed by DeepSeek.

## Where to ask

- Questions, setup help, and usage discussion: [GitHub Discussions](https://github.com/xydadada/adhd-one/discussions).
- Reproducible ADHD One desktop-shell bugs: [Bug report](https://github.com/xydadada/adhd-one/issues/new?template=bug.yml).
- Feature proposals for the desktop shell: [Feature request](https://github.com/xydadada/adhd-one/issues/new?template=feature.yml).
- Official Harness behavior, CLI/Web UI, or upstream provider protocol: [DeepSeek Harness issues](https://github.com/deepseek-ai/DeepSeek-Harness/issues).
- Security vulnerabilities: [private vulnerability report](https://github.com/xydadada/adhd-one/security/advisories/new), never a public issue.

Before posting, remove API keys, Authorization headers, full environment dumps, private workspace paths, session content, and unredacted logs. Provider Doctor reports are designed to be shareable, but must still be reviewed by the user.

Windows 11 x64 is the target platform. Unsigned prerelease builds may trigger SmartScreen, and the current source/static qualification does not claim clean-machine, performance, or real-provider validation.
